
- The repository is http-cookie: a repository is named after what it handles, in the singular, with the prefix `http-`
  for a part of an HTTP message (plan N-1, N-2). Every name follows it (design P-1, E-2): the crate
  `polyspec-http-cookie`, the Composer package `polyspec/http-cookie` with the namespace `Polyspec\HttpCookie` and the
  extension `polyspec_http_cookie`, the PyPI package `polyspec-http-cookie` with the module `polyspec.http_cookie`, the
  npm package `@polyspec/http-cookie` and the error classes `HttpCookie<Category>Error`. The contract records the
  change in `changes`.
